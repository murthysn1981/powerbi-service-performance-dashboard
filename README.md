# Power BI Service Performance Dashboard

## 📌 Project Overview
This project analyzes service operations using Power BI to monitor service performance, pending calls, turnaround time (TAT), backlog ageing, and regional performance.

The objective is to transform service data into actionable insights that support decision-making, improve SLA compliance, and identify areas requiring operational attention.

## 🎯 Business Objectives
- Monitor service call closure performance and TAT.
- Analyze pending service calls and backlog ageing.
- Compare performance across regions and service partners.
- Identify overdue calls and operational bottlenecks.
- Support data-driven decisions to improve service efficiency.

## 📊 Key Performance Indicators (KPIs)
- Total Service Calls
- Closed Calls
- Pending Calls
- TAT Compliance %
- Overdue Calls
- Backlog Ageing
- Regional Performance
- Service Partner Performance

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query for data transformation
- DAX for measures and calculations
- Data visualization and business reporting
